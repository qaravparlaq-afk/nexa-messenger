# NEXA UI Direction

## Design language
Minimal, premium, calm, privacy-first. NEXA should not visually clone Telegram, WhatsApp, Signal or iMessage.

## Navigation
Chats · Calls · Wallet · Settings

## Brand
The supplied wing/bird mark is the visual reference for the NEXA identity. Production assets will include transparent SVG/PNG, monochrome variants, light/dark variants, Android adaptive icon and iOS app icon.

Suggested starting purple range: #7C3AED–#8B5CF6. Final colors must pass contrast/accessibility checks.

## Primary screens
Welcome, identity setup/restore, chat list, conversation, attachment picker, call screen, contact profile, verification, Security Center, Wallet, payment, Settings, Privacy and Devices.

## Security UX
- Never hide a key-change warning.
- Never claim E2EE unless it is actually enforced.
- Show verification state clearly.
- Make device revocation easy.
- Explain backup/recovery trade-offs before enabling them.
